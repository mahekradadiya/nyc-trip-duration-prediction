# Processed Data

This directory stores the processed datasets generated during data preprocessing and feature engineering.

Processed data is **not included** in this repository because it can be reproduced by running the preprocessing pipeline.

To generate the processed data:

1. Download the raw dataset and place it in `data/raw/`.
2. Run the preprocessing and feature engineering scripts or notebooks.
3. The generated files will be saved in this directory.

This folder is intentionally kept empty in the repository.
